## Compatibility reference

`onelua-reference/` contains the OneLua API notes used as the compatibility
target. These are reference material, not a description of OpenLua's current
implementation. When they disagree with the code, [API.md](API.md) wins.

`archive/` keeps historical design notes. They may describe APIs that were
never implemented or have since changed.
