Allows to save the game. 
Parameters
    dataData to save (up to 256 chars). 
    gametittleTitle which is shown on the VSH or the save/load dialog (up to 128 chars). 
    gameidOur game ID, specially for distinguish our savedatas (up to 13 chars). 
    subtittleSavedata subtitle (up to 128 chars). 
    descriptionDetails or description of the savedata (up to 1024 chars). 
    modeMode of saving data:
0 For show save dialog (5 slots).
1 Autosave (dialog not shown).
    resourcesPath which contains the resources which will be saved or shown in our savedata. The resources you can customize are these, and must match the name:
ICON0.PNG Savedata icon, size 144*80.
ICON1.PMF Video to be shown on the savedata (only at XMB).
PIC1.PNG Background image for the savedata, size 480*272
PREVIEW.PNG Icon to be shown in the save dialog.
SND0.AT3 Sound to play in the savedata, .at3 format and XMB only.
Returnstrue If save success or false otherwise.
